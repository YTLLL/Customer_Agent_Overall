# Calling Agent Frontend

This is the frontend application for the Calling Agent. It provides a user interface for initiating calls, sending text messages, and viewing call transcripts.

## Setup

1. Install dependencies:

   ```
   npm install
   ```

2. Run the development server:

   ```
   npm run dev
   ```

3. Build for production:
   ```
   npm run build
   ```

## Features

- User-friendly interface for initiating calls
- Real-time call status updates
- Live text input for sending messages during calls
- Call transcript display
- Support for both flight and hotel operations

## Configuration

The frontend connects to the backend API. Make sure the backend is running and update the API URL in the code if needed.
